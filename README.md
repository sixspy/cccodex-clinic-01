# cc-clinic-lab · 临床试验访视采集台

数据工程产品线基线。题号前缀 `clinic-*`，默认端口 **7600**。

## 技术栈

- 后端：CherryPy + SQLite
- 前端：原生 JS SPA（顶栏薄荷绿丝带导航）
- 会话：itsdangerous 签名 Cookie
- 测试：pytest + httpx（依赖已列入 requirements）

## 登录

- 地址：`http://127.0.0.1:7600/login`
- 账号：`admin` / `123456`

## 页面

| 页面 | 能力 |
|------|------|
| 试验中心 | 中心登记、启停/观察、配额、方案版本生效、窗止点与钉水位 |
| 访视批次 | 开批、模拟抓取（只开窗止点之后的新窗）、追加访视行、合格入库、收齐/关闭、水位徽标 |
| 字段质控 | 按批/全量扫描、发现关闭/重开 |
| 缺口补采 | 排队、执行成功/失败、失败重试 |
| 访视对账 | 缺口/发现/补采对照、中心矩阵（含窗止点）、审计 |
| 台参数 | 设置读写、水位钉点口径 |

## 主链

中心 → 水位落点（钉窗止点）→ 访视批次抓取 → 质控发现 → 缺口补采 → 对账报告；设置与审计贯穿写操作。

### 水位账册（甲路）

`watermark_ledger` 是独立账册，钉住每个中心当刻的窗 `window_start → window_end` 与窗指纹；
访视侧只读账册，抓取只从最新落点的 `window_end` 往后开新窗，旧窗永不重灌。

- 无水位落点行：抓取与入库都挂起，白话提示先钉窗止点。
- 水位徽标与窗止点指纹拧花：拦下抓取与入库，须重新钉水位落点。
- 钉点走 `BEGIN IMMEDIATE` 写锁串行，同一窗止点唯一索引兜底，两名仓管并发钉同一中心不会互相覆盖。

## 本地

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
pytest
python run.py
```

Docker：`docker compose up -d --build`，健康检查打 `/login`。
